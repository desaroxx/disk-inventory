# Changelog

## 1.0.0 — 2026-11-11

First public release.

- Volumes window listing mounted drives, plus Open Folder for any folder, volume or bundle.
- Parallel scanner (`getattrlistbulk`) with physical and logical sizes; hard links counted once.
- File outline and squarified cushion treemap with synchronised selection, zoom in and out,
  and Zoom Out To.
- File kind statistics with the 12-colour kind palette, selection list, and Information panel.
- Optional free-space and other-space tiles, package contents, horizontal split.
- Cleanup suggestions: Xcode DerivedData, simulator and app caches, `node_modules`, `.build`,
  `target`, installers and old downloads, each marked Safe or Check first. Ticked items move
  to the Trash together.
- Universal (Apple silicon and Intel) app for macOS 15 or later, shipped as a DMG and a zip.
